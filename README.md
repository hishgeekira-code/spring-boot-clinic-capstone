# 🏥 Clinic Appointment Booking System

Эмнэлгийн эмч нарын хуваарийг удирдах, цаг товлох, үйлчлүүлэгч болон админы эрхээр захиалгын урсгалыг бүрэн зохицуулах зориулалттай Spring Boot болон Thymeleaf суурьтай цогц вэб систем.

---

## 📌 Онцлох боломжууд (Key Features)

### 👤 Хэрэглэгчийн тал (Customer View)
* **Нэвтрэлт & Бүртгэл**: Spring Security-ээр хамгаалагдсан бүртгэл болон нэвтрэх систем.
* **Эмч хайх & Шүүх**: Тасаг болон нэрээр эмч нарыг шүүж, дэлгэрэнгүй профайл үзэх.
* **Цаг захиалах**: Сул хуваарийг харж, шалтгаан бичин цаг товлох (давхар захиалга үүсэхээс сэргийлсэн хамгаалалттай).
* **Миний захиалгууд**: Өөрийн товлосон цагуудыг хянаж, шаардлагатай үед цуцлах (Cancel).

### 🛠️ Админ тал (Admin Dashboard)
* **Статистик тойм**: Нийт захиалга, эмч, тасгийн тоон үзүүлэлтүүд бүхий аналитик самбар.
* **Хуваарийн удирдлага (CRUD)**: Эмчийн ажиллах өдөр, цагийг бүртгэх, засах, устгах.
* **Захиалгын хяналт & Төлөв солих**: Үйлчлүүлэгчдийн захиалгыг бодит цагт (Pending, Confirmed, Completed, Cancelled) хуудсыг дахин ачааллахгүйгээр шууд өөрчлөх.
* **Эмч & Тасгийн удирдлага (CRUD)**: Эмнэлгийн тасаг, эмч нарын мэдээллийг удирдах.
* **Хуудаслалт (Pagination)**: Их хэмжээний өгөгдлийг цэгцтэй хувааж харуулах.

---

## 🛠️ Ашигласан технологиуд (Tech Stack)

* **Backend**: Java 17+, Spring Boot, Spring Data JPA
* **Security**: Spring Security (Role-based: `CUSTOMER`, `ADMIN`)
* **Frontend**: Thymeleaf, Vanilla JavaScript (Fetch API), CSS3 (Flexbox & Grid)
* **Database**: PostgreSQL
* **Tools**: Git, GitHub, Maven# spring-boot-clinic-capstone
